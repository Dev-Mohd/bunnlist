# Agent skills

Claude Code loads these skills automatically in every session opened on this repo.

- Marketing (53 skills, e.g. `aso`, `launch`, `copywriting`, `social`, `seo-audit`): from [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills), MIT, see `LICENSE-marketingskills`.
- Remotion video (13 skills, `remotion-*`): from [remotion-dev/remotion](https://github.com/remotion-dev/remotion) `packages/skills`. Remotion is free for individuals and small companies; see `LICENSE-remotion.md`.

To update, copy the latest `skills/` folders from those repos over these.
